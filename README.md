## Install
1. Download the latest `.apk` from [Releases](https://github.com/substring-projects/SaveBhai-Download/releases/latest) on your Android phone.
2. Open it and allow **Install unknown apps** for your browser if asked.
3. Tap **Install**.

Requires Android 7.0 or newer.
