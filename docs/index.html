How to install

SaveBhai is distributed as an APK, outside the Play Store. Installing takes under a minute.

  1. 1
    Download the APK

    Tap Download APK on this page from your Android phone.

  2. 2
    Open the file

    Open it from your notifications or the Downloads folder.

  3. 3
    Allow "Install unknown apps"

    If asked, tap Settings and allow your browser to install apps, then go back.

  4. 4
    Tap Install

    Open SaveBhai and allow notifications so you can see download progress.

To update, download the newer APK and install it over the old one. Your downloads are kept.
